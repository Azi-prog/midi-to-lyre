# midi-to-lyre
midi-to-lyre — MIDI形式のファイルを原神のライアー用文字楽譜に変換するツール

ブラウザだけで使える、無料のMIDI変換ツールです。

🎵 ツールを使う： ［https://azi-prog.github.io/midi-to-lyre/ ］

MIDIファイルを読み込み、音名やキーボードのキーを使った文字の楽譜に変換できます。変換結果はテキストファイルとして保存できます。

🎹ツールの使い方
1.midiファイルを用意します。このmidiファイルはC3~B5の音域内且つピアノの白鍵部分(ドレミファソラシ)の音のみで作成してください。また、全トラックを参照するため楽譜に関わらないトラックは一時的に削除してからmidi出力を行ってください。
2.上のURLからツールを開いて、用意したmidiファイルをドロップしてください。
3.各種表示設定を選択します。下に曲の特徴ごとに推奨する設定を置くので参考にしてください。
4.設定が完了したらテキストに変換を押します。変換された楽譜に問題がなければ、変換結果からコピペorTXT(テキスト)ファイルをダウンロードしてください。

🔍表示設定について
・音の表記形式
日本語：ドからシの音名と、1~3の音高を示す数字が組み合わさった表記です。例としてド1は音名がドであり、下から1列目の低いドであることを示します。midiファイルではC3に該当し、一番高いシ3がB5に該当します。
英語：日本語のものをローマ字表記にしたものです。好みで使い分けてください。
キーボード：PCで文字を入力する際に使う一般的なqwerty配列のキーボードで演奏する時に、入力するキーを表記しています。PCキーボード勢には使いやすいと思いますが、スマホなどその他デバイスでの演奏には使えません。
・「-」1個の長さ（休符単位）
休符としての意味を持つ「-」のマークをどれくらいの細かさで配置するかの設定です。
細かくすればするほど、音と音の間隔が分かりやすくなる一方で楽譜が長くなります。
ゆったりとした曲では8分音符相当、テンポの早い曲では32分音符相当といった感じで使い分けてください。
・何小節ごとに改行するか
改行される頻度を小節単位で設定できます。頻度を低くすると横長の楽譜になり、頻度を高くすると縦長の楽譜になります。
難易度の高い曲だと1小節当たりの音数が増え、改行頻度によっては見切れる場合もあるため、改行頻度を高くすることをお勧めします。
また、多くの曲は4小節,8小節単位など偶数小節のまとまりで出来ているため、偶数小節に設定することをお勧めします。
・最初に改行する小節番号
最初の改行タイミングを設定できます。最初の改行が行われた後は1つ前で設定した頻度で改行が行われます。
アウフタクト(弱起)などの影響で中途半端な小節から曲が始まる場合に、キリがいいフレーズの開始する小節で改行することで、楽譜の改行タイミングが良くなります。
1小節目から問題なく曲が始まる場合は1を設定し、1小節目に少し音が入り2小節目から曲が始まるような場合は2を設定するといった感じに数字を入れてください。

🔒 ファイルの安全性について

MIDIファイルは、利用者のブラウザ内で読み込んで処理します。

このツールのソースコードには、MIDIファイルを外部サーバーへ送信する処理を設けていません。

外部のJavaScriptライブラリを読み込まず、HTMLファイル単体で動作します。

ソースコードはGitHubで公開しており、誰でも確認できます。

注意： この説明はツールの実装に基づくもので、第三者によるセキュリティ監査を受けたことを意味するものではありません。機密性の高いMIDIファイルを扱う場合は、ソースコードを確認したうえでご利用ください。
※このコードはAIによって制作したものです。実際に動作確認は行いましたが何かしらの不具合が起きる可能性があります。また、正常に変換できたように見えても念のため確認をしてください。
